# 27. SERVIDOR

Asumir servidor Linux con Docker instalado.

No modificar firewall automáticamente.

No modificar configuraciones existentes de Nginx.

Documentar opcionalmente cómo hacer reverse proxy:

dominio -> localhost:3000

Ejemplo Nginx:

location / {
proxy_pass http://127.0.0.1:3000;
proxy_http_version 1.1;
proxy_set_header Host $host;
proxy_set_header X-Real-IP $remote_addr;
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
proxy_set_header X-Forwarded-Proto $scheme;
}

Pero NO aplicar estos cambios automáticamente.
